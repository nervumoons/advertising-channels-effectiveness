# Эффективность рекламных каналов — август–сентябрь 2026

Тестовое задание «Маркетинговый аналитик» (Academy TOP). Отчёт об эффективности рекламных каналов, собранный из трёх учебных выгрузок: рекламные расходы, сделки CRM и платежи.

> Данные и цифры примерные, подготовлены специально для задания и не являются точной отчётностью академии.

## Что в репозитории

| Файл | Назначение |
|---|---|
| `effectiveness_of_advertising_channels_public.ipynb` | Публичный ноутбук-отчёт: загрузка → диагностика → правила учёта → объединение → итоговая таблица → графики → контроль → выводы. Исполнен целиком (Restart & Run All). |
| `01_ad_costs.csv`, `02_crm.csv`, `03_payments.csv` | Исходные данные (не изменяются). |
| `output/report_by_channel.csv` | Итоговая таблица «канал × месяц» (генерируется ноутбуком). |
| `output/validation.csv` | Таблица проверок полноты объединения и сходимости сумм (генерируется ноутбуком). |

Приватная версия ноутбука с реальной ссылкой на папку Google Drive в репозиторий не включается (см. `.gitignore`).

## Быстрый старт (локально)

Требования: Python 3.10+, pandas, matplotlib, seaborn, jupyter.

```bash
git clone <repo-url>
cd <repo>
jupyter lab effectiveness_of_advertising_channels_public.ipynb   # Kernel → Restart & Run All
```

Три CSV лежат рядом с ноутбуком — загрузчик найдёт их автоматически.

## Запуск в Google Colab

1. Откройте ноутбук в [Colab](https://colab.research.google.com): `File → Upload notebook`.
2. В ячейке загрузки данных подставьте ID своей папки Google Drive в константу `DRIVE_ID` (или загрузите три CSV в `/content` вручную — тогда ноутбук возьмёт их оттуда).
3. `Runtime → Run all`. Итоговая таблица и проверки появятся в `/content/output/`.

## Как обновить отчёт

Дописать строки того же формата в любой CSV → перезапустить ноутбук целиком. Итоговая таблица, графики, проверки и выводы пересчитаются автоматически, ручного переноса итогов нет — это проверяется смоук-тестом в разделе 9 ноутбука.

## Ключевые результаты (август–сентябрь 2026, платные каналы)

- **CPL** (стоимость заявки): VK 277 ₽ < Telegram 421 ₽ < Yandex 507 ₽.
- **CR в оплату**: Yandex 32,5% > Telegram 26,2% > VK 14,3%.
- **ROMI по когортам**: Telegram +3 123% ≈ Yandex +3 021% > VK +2 594%.
- Расходы за период — 844 551 ₽; все жёсткие проверки контроля сходятся до рубля (16/16 PASS).

Полный разбор правил учёта, ограничений и числовых выводов — в ноутбуке (разделы 2, 6–8).
